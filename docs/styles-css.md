# styles.css の説明

`styles.css` は、サイトの見た目とレイアウトを担当するファイルです。

現在のプロトタイプでは、縦スクロールのスライド表現、巨大な見出し、選択肢カード、フォーム、SVGグラフ、進捗ドット、スマホ対応がこのファイルにまとまっています。

## 主な役割

- 色やフォントを決める
- スライドを画面いっぱいに表示する
- スクロールスナップを有効にする
- 選択肢カードやボタンの見た目を作る
- 結果グラフの枠や点の色を指定する
- スマホ向けにレイアウトを変更する
- `prefers-reduced-motion` に対応する

## 重要なCSSのまとまり

| セレクタ | 役割 |
| --- | --- |
| `:root` | 色などの共通変数を定義しています。 |
| `.snap-scroll` | 縦スクロールと scroll-snap の親要素です。 |
| `.slide` | 1枚のスライドの基本レイアウトです。 |
| `.choice-grid` | 選択肢カードを2列に並べます。 |
| `.choice-card` | 選択肢ボタンの見た目です。 |
| `.reason-form` | 理由入力フォームのレイアウトです。 |
| `.scatter-chart` | 結果グラフのSVGの見た目です。 |
| `.tooltip` | 回答理由を表示する吹き出しです。 |
| `.progress` | 右側の進捗ドットです。 |
| `@media (max-width: 760px)` | スマホ向けの調整です。 |

## レスポンシブ対応

現在は次の工夫があります。

- `clamp()` で文字サイズや余白を画面幅に応じて変えている
- `width: min(1180px, 100%)` のように最大幅を制限している
- スマホでは `.choice-grid` を2列から1列に変えている
- ボタン群はスマホで折り返せるようにしている

## 初心者向け: clamp()

`clamp(最小値, 変化する値, 最大値)` は、レスポンシブなサイズ指定に便利です。

例:

```css
font-size: clamp(3rem, 14vw, 5.2rem);
```

これは「最小3rem、基本は画面幅の14%、最大5.2rem」という意味です。

## 初心者向け: scroll-snap

`scroll-snap-type` と `scroll-snap-align` を使うと、スクロールしたときにスライド単位でピタッと止められます。

このプロジェクトでは、`main.snap-scroll` がスクロールの親で、各 `.slide` が止まる位置です。

## React化した場合のCSS方針

React に移行しても、最初はこのCSSを大きく変えずに使えます。

ただし、component 分割に合わせて次のように整理すると読みやすくなります。

```text
styles/
├─ base.css
├─ slides.css
├─ form.css
├─ chart.css
└─ responsive.css
```

または、Vite / React の場合は component ごとのCSSにしてもよいです。

```text
components/
├─ ChoiceCards.jsx
├─ ChoiceCards.css
├─ ResultChart.jsx
└─ ResultChart.css
```

## 編集時の注意点

- `h1` / `h2` の文字が非常に大きいため、長い日本語を入れるとスマホで崩れやすいです。
- `height: 100vh` はスマホブラウザのアドレスバーの影響を受けることがあります。必要なら `100dvh` の利用を検討してください。
- `.scatter-chart` は `viewBox` に依存しているため、SVG内の座標計算は `script.js` 側とセットで考えてください。
- 色変数は `:root` にまとまっているので、配色変更はまずここから行うと安全です。
- カードやボタンのホバー演出は、スマホでは発火しないことが多いです。タップ時の状態も確認してください。

## アクセシビリティ

- `prefers-reduced-motion: reduce` への対応が入っているのは良い点です。
- 色だけで選択状態を伝えないように、将来はアイコンやテキスト補助も検討してください。
- 進捗ドットは現在 `span` なので、クリック操作を追加するなら `button` にする方が自然です。
